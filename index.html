📖 How to Use MathLab Pro

🚀 Getting Started

This is a Flask-powered web app. Each card represents a mathematical program. Simply enter the required values and click the Calculate button to get instant results.

🛠️ Running Locally (Flask Setup)

# 1. Install Python 3.8+
# 2. Install Flask
pip install flask

# 3. Run the app
python app.py

# 4. Open browser at
http://localhost:5000

📁 Project Structure

mathlab/
├── app.py ← Flask backend
├── templates/
│ └── index.html ← This page
└── static/ ← CSS/JS assets

🔢 Available Programs

  • Odd/Even Checker — Determines if a number is odd or even using modulo
  • Grade Calculator — Converts marks to letter grades + GPA
  • Multiplication Table — Generates table up to any limit
  • Pass/Fail Checker — Multi-subject pass/fail with averages
  • Leap Year Detector — Checks divisibility rules for leap years
  • Factorial Calculator — Computes n! with step display
  • Prime Number Checker — Primality test using square root method
  • Fibonacci Sequence — Generates n terms with bar visualization
  • BMI Calculator — Body Mass Index with health category
  • Simple Interest — SI = (P × R × T) / 100
  • Quadratic Solver — Finds real or complex roots via discriminant
  • Temperature Converter — Converts between °C, °F, and K

💡 API Endpoints

POST /api/odd_even → { number }
POST /api/grade → { marks }
POST /api/table → { number, limit }
POST /api/pass_fail → { subjects: [s1,s2...] }
POST /api/leap_year → { year }
POST /api/factorial → { number }
POST /api/prime → { number }
POST /api/fibonacci → { count }
POST /api/bmi → { weight, height }
POST /api/simple_interest → { principal, rate, time }
POST /api/quadratic → { a, b, c }
POST /api/temperature → { value, unit }

🎨 Tech Stack

  • Backend: Python 3 + Flask
  • Frontend: HTML5, CSS3, Vanilla JS
  • Fonts: Orbitron + Exo 2 (Google Fonts)
  • API: JSON REST via fetch()
